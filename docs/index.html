What The Live Version Does

  • Monitors WhatsApp group messages for disaster requests
  • Parses India-based locations, needs, urgency, and contacts
  • Normalizes incoming reports into a single JSON format
  • Stores reports and serves them through an Express API
  • Supports filtering, search, deletion, and GPS handoff from the dashboard
